Rede Sesc de Educação · Design System

Audit & roadmap

Where the system stands against a production-grade brand system: foundations, component coverage, accessibility, and the artefacts still needed to express the brand in full.

Solid

Foundations

Colour, type, spacing, effects

266 token declarations across 8 files: the 20 official brand hexes, semantic aliases, accent tints, warm-neutral ramp, fluid type scale, 4px spacing, radii and shadows.

Components

36 primitives with types & usage notes

Every component ships .jsx + .d.ts + a .prompt.md with brand-specific do/don't guidance.

Voice

Content fundamentals documented

Tone, person, casing, keyword bank and headline patterns in Portuguese — rare in a first-pass system and what keeps generated copy on-brand.

Added in this pass

Layout

Layout & z-index tokens

Breakpoints, container widths (incl. --container-prose), 12-col grid, section rhythm, a stacking scale and a 44px hit-target token — previously every page re-invented these.

A11y

Global focus, selection, reduced motion, print

:focus-visible now uses the ring token everywhere, prefers-reduced-motion is honoured system-wide, and a print reset was added.

Colour

Semantic surfaces + data-viz sequence

Success/warning/danger/info tint surfaces, a 6-step chart sequence built from the "rede" accent families, state layers and an overlay scrim.

Components

Accordion · DataTable · Stat · Stepper · Textarea · Skeleton

The six patterns an education network actually needs and could not build before: FAQ, turmas tables, impact figures, enrollment progress, long-answer fields and loading states.

Closed in the completion pass

Brand

Cubo impossível + photography direction

BrandMotif ships the motif as a geometric construction with placement rules, and an imagery card now defines crops, radii, scrim treatment, alt text and consent.

Templates

Four starting points

Institutional deck (1920×1080, print/PPTX-ready), program detail page, printable A4 matrícula form, landing page — each loading the system through its own ds-base.js.

Components

Menu · FilterChips · FileUpload · DateField

The navigation and enrollment gaps are closed: regional dropdowns, program filters, document upload and deadline-aware date fields.

Theming

Dark + high contrast

[data-theme] re-maps semantic tokens only; brand hexes are untouched and components needed no changes.

Closed in the soundness pass

Tokens

Name collision fixed · accent tints added

--text-body was both a colour and a font size, so one of the two silently broke in every theme. The size is now --text-body-md. New --tint-* / --tint-*-ink pairs replace the hard-coded chip colours that made Badge, Alert and Tag render light-on-light in dark mode.

A11y

Keyboard contracts implemented

Checkbox, Radio and Switch were unreachable by keyboard (display:none on the native input). Tabs now implements the ARIA tablist pattern, Modal traps and restores focus and closes on Escape, Tooltip opens on focus, ProgressBar exposes its value.

Tooling

index.js · checks · generated docs

The public entry point the lint rules always assumed now exists. npm run check verifies file completeness, bundle freshness, token collisions, undefined var() and a11y regressions; npm run sync keeps _ds_bundle.js, the manifest and the docs true to source.

Docs

AGENTS.md · recipes · starters

One working guide for anyone generating from this system, plus recipes, an authoring checklist, a QA checklist, and blank page / React / A3 poster starters.

Closed with the official artwork
