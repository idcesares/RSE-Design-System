Themes re-map semantic tokens only — surfaces, text, borders, primary and status colours. Brand hexes never change. Set data-rse-theme="dark" or "contrast" on <html> or on any subtree (as above). Components need no changes because they never reference raw brand hexes.

Dark mode is for product/logged-in surfaces, not the public marketing site — the cream page is a brand signal. High contrast raises borders and text to WCAG AAA and removes shadows; it is the accessibility fallback, not a style.
