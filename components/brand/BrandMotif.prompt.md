# BrandMotif — cubo impossível

The **official** motif — the brand's central visual idea (reach, expansion, flexibility, lateral
thinking), supplied by Sesc as vector artwork and split into its six constructions. This replaces
the geometric placeholder that shipped earlier.

```jsx
<BrandMotif variant="cube" size={240} />
<BrandMotif variant="interlock" size={320} opacity={0.35} />   // behind a hero
<BrandMotif variant="chain" size={200} title="Motivo institucional da Rede" />
<BrandMotif variant="cube" hue="purple" size={240} />          // restated in another family
```

| variant | supplied hue | what it is |
| --- | --- | --- |
| `cube` | green | the solid isometric cube — the base mark |
| `interlock` | blue | two cubes passing through each other |
| `bar` | green | a cube pierced by a bar that could not pass through it |
| `frame` | pink | an open frame with two impossible voids |
| `chain` | pink | a zig-zag chain of bars, the widest construction |
| `hollow` | blue | a cube opened out around a hollow centre |

`hue` accepts `green`, `blue`, `pink`, `purple`, `orange`, `yellow`.

**Rules**

- One construction per composition, in negative space (corner of a band, beside a section eyebrow),
  at 25% or less of the composition. Two competing motifs read as decoration and lose the meaning.
- **The geometry belongs to the artwork; the hue is a choice.** A motif never re-maps per theme,
  exactly like the logo. Left alone it renders the exact fills Sesc supplied. Sesc's sheet only
  covers green, blue and pink, so `hue` is how purple, orange and yellow are reached — ramps come
  from the manual's published palette, never from sampling the artwork, and the remap keeps each
  face's luminance rank so the solid still reads as a solid. Say "derived" when it matters: those
  three hues are ours, not supplied, and official artwork should replace them if it arrives.
- Never redraw, rotate, distort or animate a construction.
- Drop `opacity` to ~0.3 when it sits behind content, and never place text on the cube faces.
- It is not a logo: it never substitutes for the selo, nor sits beside it in a lockup.
- For a full-bleed field of cubes rather than one construction, use the official pattern
  backgrounds in `assets/patterns/` as a CSS background image — see `docs/recipes.md`.

Decorative by default (`aria-hidden`); pass `title` in pt-BR only when the motif carries meaning on
its own.

`BrandMotif.jsx` is generated by `scripts/build-motifs.mjs` from
`assets/motifs/cubes-official.svg` — edits to it are overwritten.
