# showcase/ — the system, shown

`index.html` is a single, self-contained document that presents this design system to a
non-technical audience (leadership, partners, new team members) while doubling as a live
reference for the people who build with it.

Open it by double-clicking `index.html`. No server, no `npm install`, no network.

## What makes it different from the guideline cards

The cards in `guidelines/` are specimens: one idea each, rendered small. This page is the
argument. It opens with why the system exists, shows the same page built with and without it,
then walks the foundations, the 36 components, the three themes and the finished artefacts — in
the order you would present them to someone deciding whether to fund the work.

The system's open caveats (no photography yet, no Pantone, the unknown Sab.IA address) are **not**
in this page by the owner's decision; they live in `readme.md` and `AGENTS.md`. Keep them in mind
when the page is shown, because the placeholder content inside the artefacts is still placeholder.

## It cannot drift

Nothing on the page is transcribed by hand:

| What you see | Where it comes from |
| --- | --- |
| Every component demo | `dist/rse.js` — the same file the templates execute |
| Palette, CMYK, scales | `brand.json`, via the generated `showcase-data.js` |
| Component list, props, counts | `rse.manifest.json` + `docs/components.md`, same route |
| Semantic token values | measured from the live DOM with `getComputedStyle` |
| Contrast ratios | computed from those measured values with the WCAG formula |
| The four artefacts | the real template files, running in `<iframe>` |

Change a token and the page changes with it. `showcase-data.js` is regenerated by
`npm run sync` and verified by `npm run check` — a stale one fails the build.

## Files

```
index.html         the document
showcase.css       page chrome — layout geometry only, every colour a token
showcase.js        renders the demos, measures the DOM, drives the theme switch
showcase-data.js   GENERATED by scripts/build-showcase.mjs — do not edit
```

React 18.3.1 UMD lives in `../assets/vendor/`, so the page never
reaches for a CDN.

## Sharing it

- **By file** — send the whole repository folder, or zip it. The page reaches `../assets/`,
  `../styles.css`, `../dist/rse.js` and the templates, so it needs its siblings to work.
- **By link** — serve the repository root over any static host; the page is at `/showcase/`.
- **As a PDF** — print to PDF. A print stylesheet hides the navigation and the technical
  drawers, and keeps sections from breaking across pages.

## Reading the accessibility section honestly

The contrast table measures and reports, including failures. Switching it on for the first time
found three real defects — `--rse-color-text-muted` at 3.56:1 on the cream page, `Footer`'s note at 3.53:1 on
ink, and every control's resting border at 1.61:1. All three are fixed (see CHANGELOG), and the
table now reads 9 of 9 in light, dark and high contrast.

Those numbers are not decoration: if a token changes, the verdicts change with it. Do not "fix"
the table — fix the tokens.
